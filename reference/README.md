# Original Artwork Reference

These photographs document the physical painting that inspired the Palembang graphic system.

- `original-artwork-front.jpeg` — near-square frontal view of the painting.
- `original-artwork-context.JPG` — wider contextual photograph showing the physical object and surroundings.

They are **artistic reference**, not pixel-perfect geometry sources. The canonical digital geometry is defined by `source/Palembang.fig` and `docs/specification.md`.
