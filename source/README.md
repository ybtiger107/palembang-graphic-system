# Source Files

`Palembang.fig` is the preserved canonical Figma source supplied for this project.

`extracted/` contains the archive members extracted without modification:

- `canvas.fig`
- `thumbnail.png`
- `meta.json`
- `images/` — empty in the supplied source

The source archive itself is authoritative. The extracted directory is provided for inspection and reproducibility.

Use `python3 scripts/verify.py` from the repository root to verify preserved-file hashes.
