# Visual License Scope

This document explains which parts of the Palembang Graphic System are licensed for open reuse, and which parts are not. It is a scope document that points to a standard, unmodified license — it is not a custom legal license text.

## 1. What is CC BY 4.0 licensed

The following are licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**:

- [`docs/specification.md`](docs/specification.md) — the design/implementation specification;
- [`tokens/palembang.v1.json`](tokens/palembang.v1.json) — the machine-readable design tokens;
- files published by this project under `assets/variants/`;
- visual outputs (SVG, raster, or otherwise) generated by an official Palembang renderer, such as [`implementations/svg`](implementations/svg/);
- visual outputs generated by the future official Palembang Playground;
- SVG or raster files distributed as GitHub Release assets of this project, unless an individual file is explicitly marked otherwise.

CC BY 4.0 permits commercial use, non-commercial use, copying, redistribution, modification, recoloring, adaptation, embedding in software, use in web/mobile/desktop products, printed use, and derivative visual work, subject to attribution. It has no "NonCommercial" or "ShareAlike" condition. Full legal terms: <https://creativecommons.org/licenses/by/4.0/>.

## 2. What remains All Rights Reserved

The following are **not** licensed for reuse and remain All Rights Reserved:

- the original physical painting;
- [`reference/`](reference/) — photographs of the original artwork;
- [`source/Palembang.fig`](source/Palembang.fig) and [`source/extracted/`](source/extracted/);
- [`assets/canonical/`](assets/canonical/) — the canonical master PNG assets and their manifest;
- any other file explicitly identified as a protected canonical master.

Public visibility of this repository does not grant reuse rights to these files. See [`ARTWORK-RIGHTS.md`](ARTWORK-RIGHTS.md) for the provenance and stewardship context behind this boundary.

## 3. What remains MIT

Software in this repository is licensed under the **MIT License** ([`LICENSES/MIT.txt`](LICENSES/MIT.txt)):

- [`scripts/`](scripts/);
- code in [`implementations/`](implementations/) (renderer source, e.g. [`implementations/svg/render.py`](implementations/svg/render.py));
- future Playground source code;
- other software examples, unless a file explicitly states otherwise.

MIT covers the *code*. It does not by itself license the visual output that code produces — that output is covered by Section 1 above.

## 4. Examples of allowed Palembang uses

Under the CC BY 4.0 grant described in Section 1, you may, with attribution:

- use a Palembang SVG or PNG background in a commercial app, website, or product;
- recolor Palembang to match your own brand palette;
- embed a renderer-generated Palembang graphic in a game, publication, or presentation;
- adapt Palembang into a new aspect ratio or a derivative visual variant;
- redistribute a generated Palembang asset as part of another open-source project.

You may **not**, under this license, redistribute or reuse the original painting, the reference photographs, `Palembang.fig`, `source/extracted/`, or the canonical PNG masters — those remain All Rights Reserved (Section 2).

## 6. Canonical files vs. generated outputs

"Canonical" files (`assets/canonical/`, `source/Palembang.fig`, `source/extracted/`, `reference/`) are the protected masters described in Section 2 — they are not themselves open for reuse, even though the repository is public.

"Generated outputs" are new files produced *from* those canonical materials by an official renderer (for example, an SVG or PNG rendered by [`implementations/svg/render.py`](implementations/svg/render.py), or a release asset built from it). Generated outputs are licensed under CC BY 4.0 per Section 1. Generating an output does not grant any additional rights in the canonical masters themselves.

## 7. If stewardship changes later

The repository maintainer's rights in the original artwork are described in [`ARTWORK-RIGHTS.md`](ARTWORK-RIGHTS.md), including a personal commitment to cooperate with the original artist if they are ever identified and wish to reclaim rights.

CC BY 4.0 licenses already validly granted under Section 1 are not intended to be withdrawn. If rights in the underlying materials are later transferred, assigned, or returned to the original artist, that transfer is subject to licenses already validly granted to users before the transfer — consistent with how CC BY 4.0 licenses generally work (they are granted for the duration of copyright and are not revocable once given, except as the license itself provides).
