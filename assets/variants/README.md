# Derived Variants

Put non-canonical outputs here, for example:

- alternate palettes;
- texture experiments;
- resized or optimized delivery assets;
- platform-specific exports;
- intentionally modified geometry.

Never overwrite files in `assets/canonical/png/`. Record the canonical source asset or specification version used to create a derived file when that provenance matters.
